# 간호관리자 업무 수첩 — 안드로이드 설치형 앱 만들기

로컬 개발 환경 없이, GitHub 웹 화면과 GitHub Actions만으로 안드로이드 APK를 자동 빌드하는 프로젝트예요.
지금까지 BedsideLab 앱을 만드셨던 방식과 동일한 흐름입니다.

## 1. 새 GitHub 저장소 만들기
1. github.com에서 New repository → 이름 예: `ward-notebook-android` (Private 권장)
2. 이 폴더 안의 모든 파일과 폴더 구조를 그대로 업로드하세요.
   - `github.dev`(저장소 화면에서 마침표 `.` 키를 누르면 웹 에디터가 열려요)를 쓰면 파일 업로드/커밋이 편해요.
   - `.github/workflows/build-android.yml` 경로가 정확히 유지되어야 자동 빌드가 실행돼요.

## 2. 자동 빌드 실행
- `main` 브랜치에 파일을 커밋하면 자동으로 Actions가 실행돼요.
- 저장소 상단 **Actions** 탭에서 진행 상황을 볼 수 있어요. 5~10분 정도 걸려요.
- 실패하면 로그를 열어 어떤 단계에서 멈췄는지 확인하고, 그 내용을 Claude에게 보여주시면 같이 고칠 수 있어요. (이 워크플로는 표준적인 Capacitor 빌드 방식으로 작성했지만, 실제 실행은 아직 검증해보지 못했어요.)

## 3. APK 다운로드
- Actions 탭 → 완료된 워크플로 실행 클릭 → 맨 아래 **Artifacts** 섹션에서 `ward-notebook-debug-apk` 다운로드
- 압축을 풀면 `app-debug.apk` 파일이 나와요.

## 4. 폰에 설치하기
1. `app-debug.apk`를 안드로이드 폰으로 전송하세요 (카카오톡 '나에게 보내기', 이메일, USB 등 편한 방법으로).
2. 폰에서 파일을 열면 "출처를 알 수 없는 앱" 설치 허용을 한 번 물어봐요 → 허용 → 설치.
3. 홈 화면에 "간호관리자 업무 수첩" 아이콘이 생기고, 이후로는 일반 앱처럼 오프라인에서도 그대로 실행돼요.
4. 앱을 업데이트하고 싶으면 위 과정을 반복해서 새 APK를 다시 설치하면 돼요 (기존 데이터는 유지돼요).

## 비용 및 유지
- GitHub Actions는 이 정도 사용량에서는 무료 범위 안에 있어요.
- 앱스토어에 올리지 않고 개인 설치(사이드로드)만 하는 것이므로 등록비나 연 사용료가 없어요.
- 이 debug APK는 개인용 서명으로 빌드돼요 — 본인 폰에 설치해서 쓰는 용도로는 문제없어요.

## 아이폰 사용자는요? (홈 화면 아이콘까지 원하는 대로 쓰려면)
아이폰에서 매장(App Store) 없이 계속 설치된 상태로 두려면 Apple 개발자 등록(연 $99)이 꼭 필요해서,
"유지비용 없음" 조건과는 맞지 않아요. 대신 같은 내용을 담은 웹 버전을 Safari에서 열고
**공유 → 홈 화면에 추가**를 하면, 아이콘이 생기고 브라우저 주소창 없이 앱처럼 열리며 데이터도 그 기기에
그대로 저장돼요. 별도 비용 없이 가능한 가장 가까운 방법이에요.

다만 Claude 대화 안에서 보여드리는 링크(claude.ai/artifact/...)는 Claude 사이트가 그 안에 화면을 담아서
보여주는 방식이라, 아이폰이 "홈 화면에 추가"할 때 안쪽 페이지가 아니라 **Claude 사이트 자체의 아이콘**을
가져가 버려요. 그래서 앱 아이콘을 직접 만든 걸로 완전히 바꾸려면, 이 저장소를 **GitHub Pages**로 무료
호스팅해서 그 주소를 여는 게 유일한 방법이에요.

**GitHub Pages 켜는 방법 (무료, 한 번만 설정)**
1. 이 저장소의 **Settings** 탭 → 왼쪽 메뉴 **Pages**
2. "Build and deployment" → Source: **Deploy from a branch**
3. Branch: **main**, 폴더: **/ (root)** 선택 → **Save**
4. 1~2분 후 같은 화면에 `https://<본인아이디>.github.io/<저장소이름>/` 주소가 떠요. 이 주소를 아이폰
   Safari로 열고 **공유 → 홈 화면에 추가**하면, 이번엔 직접 만든 노트북 아이콘 그대로 나와요.
5. 저장소 루트에 있는 `index.html`이 바로 이 앱이라, 별도 설정 없이 그대로 열려요.

이후 앱 내용을 업데이트할 때마다 Claude가 준 새 `index.html`로 저장소의 `index.html`과 `www/index.html`
두 곳을 같이 교체해주시면 돼요.

## 데이터는 어디에 저장되나요?
모든 데이터(근무표, 일정, 메모, 비상연락망, 복무관리 파일)는 오직 그 앱이 열린 기기·브라우저 안에만
저장돼요. 서버로 전송되지 않고, 인터넷 연결 없이도 그대로 조회·입력할 수 있어요.

## 갤럭시(안드로이드) 폰도 GitHub Pages 주소를 쓸 수 있나요?
네, GitHub Pages는 그냥 일반 웹사이트라 아이폰뿐 아니라 갤럭시(크롬·삼성인터넷)에서도 똑같이 열려요.
`manifest.json`과 아이콘 파일(`icon-192.png`, `icon-512.png`)을 저장소에 같이 넣어뒀어서, 갤럭시에서
같은 주소를 크롬으로 열면 주소창에 "앱 설치" 또는 메뉴에 "홈 화면에 추가"가 뜨고, 눌러보면 같은 노트북
아이콘으로 설치돼요 — 안드로이드 쪽은 위 4단계로 만든 진짜 APK와 이 방법 중 편한 걸 쓰시면 돼요(둘 다 무료).
